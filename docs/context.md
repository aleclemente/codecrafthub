# Context Document - Learning Plataform in Java

## Development of a Learning Plataform in Java

## 1- Context and Overview

Develop a final project for "Generative AI for Software Developers" course by Coursera as part of the learning path.

The final project is a simple personalized learning platform called CodeCraftHub where developers can track courses they want to learn.

## 2- The Problem

Design the backend server-side architecture for this learning platform and develop the server-side application using Generative AI (GenAI) with Java and Spring Boot.

## 3- Objectives and Expected Results (Learning Objective)

- Design and develop software applications using GenAI
- Create documentation for the code with GenAI
- Create test cases with GenAI
- Run and test the application developed with GenAI

## 4- Scope and Key Features

### In Scope

#### Requirements

- Use Java with Spring Boot framework
- Store course data in a simple JSON text file (NO database needed)
- No authentication or user management needed
- Focus on learning REST API basics

#### Each course should track

- Course name
- Description
- Target completion date
- Current status (Not Started, In Progress, Completed)

#### Recommend

- A simple project structure for beginners
- The REST API endpoints to be created
- How to store and retrieve data from a JSON file

### Out of Scope

- not applicable
